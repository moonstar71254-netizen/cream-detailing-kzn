Инструкция по обновлению и публикации сайта Cream detailing

1. Тексты, цены, график и контакты TG/WA:
   Откройте файл src/data/siteConfig.js и поменяйте нужные строки в кавычках.

2. Фотографии:
   Положите свои фото в папку public/images/ и укажите пути (например, ./images/hero.jpg)
   в файле src/data/siteConfig.js.

3. Сборка и публикация на любой хостинг:
   Выполните команды `npm install` и `npm run build`.
   Готовые статические файлы появятся в папке dist/ — загрузите её содержимое на хостинг.
